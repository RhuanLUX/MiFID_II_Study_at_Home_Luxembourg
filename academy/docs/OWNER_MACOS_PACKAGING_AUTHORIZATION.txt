**3. PERSISTENT STORAGE**

This is a critical requirement.

The application must remember:

- Completed lessons.
- Current learning progress.
- Personal Notes.
- Existing saved reinforcement exercise data, where applicable.
- Relevant application preferences.

Progress must survive:

1. Closing and reopening the application.
2. Restarting the Mac.
3. Moving the application into the Applications folder.
4. Updating the application without intentionally deleting user data.

Use a stable application identity and reliable persistent storage.

If the existing browser storage mechanism already works reliably inside the desktop wrapper, preserve it.

If adaptation is necessary, implement the smallest safe change.

Store user data independently from the application bundle whenever appropriate.

Do not silently reset progress.

Maintain the existing backup export/import functionality.

The standalone application may start with an empty progress record. Existing browser progress does not need automatic migration, but importing a compatible backup must work.

**4. OFFLINE REQUIREMENTS**

Bundle all necessary HTML, CSS, JavaScript, educational content and translations inside the application.

No internet connection should be required to:

- Open the application.
- Read lessons.
- Access Portuguese translations.
- Answer reinforcement exercises.
- View explanations.
- Save progress.
- Take notes.
- Export or import backups.

Optional external reference links may open in the default browser, but must not be required for normal operation.

**5. MACOS BUILD**

If the current development environment is Windows, do not pretend that a Windows build produces a valid macOS executable.

Use an appropriate macOS build environment.

GitHub Actions with a macOS runner is authorized for this purpose.

Configure the necessary build workflow, execute it and verify its results.

Prefer a universal macOS application supporting both Apple Silicon and Intel Macs if practical.

If a universal build is not feasible, provide separate clearly identified ZIP packages for Apple Silicon and Intel.

Do not assume the user's Mac processor architecture.

Do not require the student to install Node.js, Python, Rust, a terminal or development tools.

The application should be ready to launch after extraction.

**6. MACOS SECURITY**

Do not disable macOS security protections globally.

Do not claim that an unsigned application will launch without a Gatekeeper warning.
